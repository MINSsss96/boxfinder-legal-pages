삭제 대상 데이터

현재 릴리스에서 박스 정보, 내용물 정보, 사진, 백업 파일은 기본적으로 이 기기 또는 사용자가 직접 내보낸 ZIP 파일에 저장됩니다. 서버 저장 기능을 사용한 이력이 확인되는 경우에만 서버 데이터가 삭제 대상에 포함될 수 있습니다.

  • 앱에 저장된 박스 정보, 내용물 정보, 사진은 앱 안 삭제, 앱 데이터 삭제, 앱 삭제로 관리할 수 있습니다.
  • 사용자가 직접 내보낸 ZIP 백업 파일은 사용자가 보관 위치에서 직접 삭제해야 합니다.
  • 향후 서버 저장 기능이 추가되고 사용 이력이 확인되는 경우, 해당 서버 저장 데이터가 삭제 대상에 포함될 수 있습니다.

현재 버전에서는 AI 검색 개선 목적으로 사진, 검색어, 검색 결과, 임베딩, 피드백을 서버에 저장하지 않습니다. 현재 출시 버전에서는 AI 검색 개선 참여 토글이나 동의 UI를 제공하지 않습니다.
